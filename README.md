# AI Video Task Workstation (VideoTaskHub)

一个基于 **PyQt5 / PyQt6** 的桌面端“任务/素材整理”工具，集成了 **批量建文件夹、批量重命名、自动分类、素材对位匹配、视频整合、批量视频水印** 等能力，并支持通过 **AI（远程 API / 本地大模型 / CLIP）** 辅助完成素材匹配与审核。

当前公开发布版本为 **v1.4.0 — GPL Release**。

> 当前主入口：`main-dev.py`。首次使用运行 `安装.bat`，之后运行 `运行-dev.bat`。

源码交付目录包含程序源码、界面资源、开源字体许可证、Seed-VC 源码、安装与构建脚本及依赖清单。虚拟环境、模型权重与缓存、用户配置、运行日志和示例媒体不属于源码，安装时按需生成或下载。

> 人声替换调用 Seed-VC 的 `inference.py`，不使用其原始 Gradio 浏览器 WebUI。为保持 Pillow 安全基线，安装器会排除 Gradio；直接运行 Seed-VC 的 `app.py`、`app_vc.py` 等 WebUI 入口不属于本发行版的受支持功能。

## 功能概览（按界面 Tab）

### 🎬 素材整理与汇总预览

- **项目化管理**：按项目创建多个标签页；支持拖拽排序、关闭项目。
- **批量自动化流水线**：
  - 选择“监控总素材根目录（A）”，扫描子文件夹批量建项。
  - 一键批量 AI 匹配：逐个项目后台执行（不会卡死界面），并显示总体进度条。
  - 匹配后自动整理（可选）：勾选“匹配后自动整理”后，匹配完成会立刻把素材按行落盘到目标目录。
  - 一键整理全部项目：手动触发对所有项目进行“物理整理”（移动/复制、写入文案 txt、导出 CSV）。
- **汇总预览与盘点**：
  - **汇总预览表**：用于集中审核/查看项目内容（含图文审核能力，支持图片 AI 审核）。
  - **图片库存报告**：统计每个项目目录图片总数、已匹配行数、剩余图片，并提示“缺图/已匹配/剩余不多”等状态。
- **全局智能 CSV 导入**：把一个汇总表（CSV/从表格直接粘贴）“智能分发”到各项目表格中。

**单个项目表格列说明：**

- `代码`
- `图片路径 (拖入/AI匹配)`
- `评分`（AI 匹配理由/分数）
- `中文文案`
- `英文文案`
- `备注 (特殊要求)`

**单个项目常用按钮：**

- `🤖 AI 智能图文匹配`：对该项目执行一次 AI 图文匹配，把匹配到的图片路径写回表格。
- `🚀 仅整理 [项目]`：只整理当前项目（移动/复制图片、写入文案文件、导出 CSV）。
- `📊 仅导出CSV [项目]`：不整理文件，仅导出 CSV。
- `✂️ 导出分段英文 [项目]`：把英文文案按“字数上限”自动分段导出为多个 `txt`。

### 🚀 智能匹配 / 视频对位

支持“视频、音频、图片”混合对位，综合多维度进行匹配（视觉语义/波形相关性/文件名等），并提供“一键重命名”。

包含两类模式：

- **普通素材对位（图片/视频/音频）**：以“参考文件/文件夹”的文件名作为命名来源，为“待匹配文件/文件夹”找到对应关系并生成新名称预览。
- **音频/视频对白对文本命名**：
  - 基于语音识别（Whisper / faster-whisper）将音频/视频内容转写，匹配到文本并用于命名。
  - 支持输出字幕：纯转写生成 SRT，或按你提供的文本块/TXT 文件顺序合并对齐生成总 SRT。
  - 也可单独导出 `SRT` 字幕或 `TXT` 转写文本。

### 📂 自动分类

对指定“源目录”进行自动归类整理；支持“编号前缀”规则（例如 `0720-C-12_3_2` 优先归到 `0720-C-12`）。

支持多种分类模式（界面下拉可选）：

- `综合智能模式`：综合多规则自动归类
- `自定义规则模式`：按你配置的关键词/匹配模式/目标文件夹名进行归类
- `按文件名匹配现有文件夹`：同级存在同名/相近文件夹时自动归入
- `按文件名前缀自动分组`：例如 `C2-0715_1、C2-0715_2` 归为同组（开始前会弹窗确认）
- `按扩展名自动分类`：按 `.jpg/.mp4/.txt ...` 等分类
- `按时间自动分类`：按创建/修改时间分到 `年/月/日` 等目录
- `提取子文件夹文件到指定目录`：把子目录文件“扁平化”提取到一个目录（可选：提取后删除空子文件夹）

提供 `撤回上次分类`（如果你误分类，可以一键撤回）。

### 📁 批量建文件夹

用于按规则或清单批量创建目录结构（适合批量开项目、批量建任务目录）。

特点：

- 创建位置支持直接粘贴/拖入路径。
- 快速输入支持：`A1-A10`、空格/逗号/换行分隔、多行粘贴。
- 支持层级路径：`A1/素材`、`A1/成片`（可关闭“允许层级路径”）。
- 冲突处理：已存在则跳过（推荐）/自动追加 `_2/_3...`。
- 可选“子文件夹模板”：例如在每个项目下自动创建 `素材/成片/字幕/封面`。
- 支持“每日自动模板”：每天启动软件时自动执行一次（可选：先创建当天主目录，日期格式默认 `%Y-%m-%d`）。
- 提供 `👀 预览` 与 `↩️ 撤销上次创建`，方便避免误操作。

### 📝 批量重命名

用于批量生成重命名预览、执行重命名；适合图片/视频等素材整理命名规范化。

包含两部分：

1. **基础批量改名工具**
   - 查找/替换（可选正则）
   - 前删/后删固定字符数
   - `🔢 自动编号`
   - `↩️ 还原`（恢复原始名）
   - `撤回上次改名`

2. **智能改名（通过 CSV 匹配）**
   - 拖入汇总 CSV（提示要求含 `代码` 与 `中文文案` 列）
   - 拖入待改名文件/文件夹（支持多选/多级子文件夹）
   - 先 `✨ 智能改名预览`，确认无误再执行


### 💧 批量视频水印（多层）

支持批量为视频添加水印，且支持多层配置（例如 logo + 角标文字等）。

### 🎞️ 视频整合

提供多个视频处理子功能（拼接/自动分段/变速/裁剪/画幅/音频/字幕/输出等），用于将素材快速整合成可交付视频。
## 推荐工作流（上手最快）

### 工作流 A：项目素材 → AI 匹配 → 一键整理落盘

1. 进入 `🎬 素材整理与汇总预览`
2. `📂 批量从文件夹建项`：选择“总素材根目录”，勾选要处理的子文件夹，程序会自动建项目（项目名默认取子文件夹的最后一级名称）并填入“素材来源目录”
3. 在每个项目表格里录入 `代码/中文/英文/备注`（图片路径可先留空）
4. 点击 `⚙️ AI 配置`，选择引擎（远程 API / 本地大模型 / CLIP）
5. 点击 `⚡ 开始一键批量 AI 匹配`
6. 如果需要自动落盘：勾选“匹配后自动整理”；否则手动点 `📦 一键整理全部项目`

### 工作流 B：两堆素材对位 → 一键重命名

1. 进入 `🚀 智能匹配 / 视频对位`
2. 在“参考文件”拖入“名字正确的一方”（文件/文件夹）
3. 在“待匹配文件”拖入“需要改名的一方”
4. 点击 `🚀 开始智能匹配` → 确认预览 → `📝 一键重命名匹配文件`

### 工作流 C：每天固定建目录

1. 进入 `📁 批量建文件夹`
2. 填好“模板根目录”，启用“每日自动创建”
3. 填写“每天要建的常见文件夹”（一行一个）
4. 可先点 `预览今日规则`，确认无误再启用


## 快速开始

### 1. 安装依赖


Windows 上双击 `安装.bat`。它会创建项目专用的 `.venv` 并按依赖清单安装环境。

可选能力依赖（用到对应功能时才需要）：

- 视频预览（可选）：`python-vlc` + 本机安装 VLC（提供 `libvlc` 运行时）
- 本地大模型（可选）：`transformers` / `accelerate` / `safetensors` / `torch`（程序会按需尝试安装）
- 语音识别（可选）：`faster-whisper`（界面中提供“一键安装”按钮）

### 2. 运行

双击 `运行-dev.bat`，或在已安装的项目环境中运行 `.venv\Scripts\python.exe main-dev.py`。

## AI 引擎配置说明

在“🎬 素材整理与汇总预览”页点击 **`⚙️ AI 配置`** 可设置 AI 引擎，支持：

- **🌐 远程 API / API 池**：配置 `API Base`、`API Key`、`Model`。支持多个 Key 组成“Key 池”，并支持随机/顺序策略与间隔限流。
- **💻 本地大模型**：加载本地模型路径（程序会尽量自动识别与兼容）。
- **⚡ CLIP 极速模式（推荐）**：走 CLIP 特征相似度进行快速匹配，默认模型为 `OFA-Sys/chinese-clip-vit-large-patch14`。

程序会将 HuggingFace 缓存目录重定向到程序目录下的 `hf_cache/`，以减少系统盘缓存异常带来的问题。

## 全局智能 CSV 导入说明（🎬 页）

入口：`🎬 素材整理与汇总预览` → `📥 全局智能CSV导入`

使用方式：

1. 从 Google 表格/Excel 全选复制（Ctrl+C）
2. 在弹出的“全功能编辑表格”里点一下表格区域，直接 Ctrl+V 粘贴
3. 程序会自动着色识别列：
   - 蓝色：代码列
   - 绿色：中文文案列
   - 黄色：英文列（若识别到）
   - 橙色：图片路径列（若识别到）
   - 紫色：项目名列（若识别到）
   - 灰色：备注列（若识别到）
4. 如识别不准，可点 `🎯 手动指定代码列` 手动指定
5. 点 `🚀 开始智能分发导入`

导入选项（弹窗底部勾选项）：

- `覆盖已有内容`：默认开启
- `允许空值覆盖(危险)`：默认关闭（一般别开，避免把已有文案覆盖成空）
- `若项目不存在则自动创建`：默认开启

## CSV 导入（默认列位）

脚本内置了一个“常用 CSV 列位”默认值（0-based 索引）：

- `code`：第 13 列（索引 `12`）
- `cn`：第 6 列（索引 `5`）
- `en`：第 7 列（索引 `6`）
- `remark`：第 8 列（索引 `7`）

如果你的 CSV 列顺序不同，请在界面导入时按提示调整/映射。

## 整理落盘的输出结构（🎬 页）

当你对某个项目执行“仅整理/一键整理全部项目”后，程序会在你设置的“整理后存放位置”下创建：

- `整理后存放位置/项目名/`
  - `代码/`（若代码为空则为 `item_序号/`；同名会自动改成不冲突的名字）
    - `代码.jpg/png/...`（图片会被复制/移动并重命名为“代码+原后缀”）
    - `中文文案.txt`（通常以中文文案内容命名；超长会自动截断并避免冲突）
    - `英文文案.txt`（同上；同时会自动按每行约 60 字符智能断行，便于后续使用）
  - `项目名_仅代码英文.csv`（无表头，2 列：代码 + 英文）
  - `项目名_中英对照汇总.csv`（带表头：代码/中文文案/英文文案）

如果同名路径冲突，会自动生成不重复的目录/文件名（例如追加 `(2)` 或 `_2` 等），避免覆盖。

- `AIPRO_INSECURE_SSL=1`：关闭 HTTPS 证书校验并屏蔽告警（仅在你明确知道风险时使用）
- `TRAE_FORCE_SOFTWARE_OPENGL=1`：强制 Qt 使用软件渲染（个别机器硬件加速白屏时可尝试）

## 常见问题

- 新电脑首次使用：双击 `安装.bat`；安装完成后双击 `运行-dev.bat`。
- 启动卡在环境检查/依赖安装：在程序目录新建空文件 `SKIP_CHECK.txt` 可跳过环境检查（仅建议你明确知道环境没问题时使用）。
- 视频预览不可用：需要安装 VLC 桌面版（提供 `libvlc` 运行时）；仅安装 `python-vlc` 可能不够。
- 批量操作建议先测试：分类/改名/移动属于“不可逆操作”，建议先在测试目录跑通流程，并使用“预览/撤回”能力降低风险。

## 免责声明

本工具涉及文件移动/复制/重命名与批量视频处理。建议在正式目录操作前先在测试目录验证流程，并做好备份，避免误操作造成不可逆损失。


Windows 发布可在 PowerShell 中运行 `build_release.ps1`。它会从项目 `.venv` 构建 **onedir** 发布目录，并按开关附带 FFmpeg、FFprobe 与 VLC Runtime。

不要再使用 `--onefile`：本项目含 Qt、Torch、faster-whisper、VLC 等大量 DLL，单文件封包每次启动都要解压到临时目录，且更容易丢失 Qt 插件、VLC/FFmpeg 与动态导入模块。

如需从命令行执行与“一键封包”完全相同的完整发布，可执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_release.ps1 -WithVlcRuntime
```

`hf_cache` 通常很大，默认不随发布包附带；需要离线分发已下载 AI 模型时再增加 `-WithModelCache`。发布时必须解压并保留完整的 `台词素材整理` 文件夹，不能只复制其中的 EXE。
